# 本地会议录音 · Meeting Scribe 0.2

Windows 桌面程序：同时录制麦克风和电脑内部音频，使用本机 NVIDIA GPU 转写。无需会议机器人，不调用云端转写或总结服务。

## 启动与使用

首次使用：安装 **Python 3.13（64 位）**，运行 **Setup.cmd** 安装依赖并下载 large-v3 和 Turbo 模型。安装完成后，双击 **Start.cmd** 启动。升级后需关闭旧窗口，再打开新版。

1. 输入会议名称；可在左侧点击 **选择文件夹** 设置录音与转写保存位置。
2. **我的麦克风**选择实际讲话使用的设备。
3. **会议声音**选择会议软件正在播放声音的耳机 / 扬声器。不是选择麦克风。
4. 默认勾选 **边录边转写 · Turbo 实时草稿**。点击 **开始录音**，确认双方讲话时对应音量条有变化。戴耳机可以减少扬声器声音被麦克风重复录入。
5. 右侧分别显示已确认草稿和 **临时文字（可能修订）**。约每 2 秒尝试更新，具体延迟随语音、GPU 负载和首次加载变化。“已确认”仅表示该段不再实时改写，不代表人工核实。
6. 点击 **结束并保存** 后，会先保存音频，再补完实时草稿尾句。暂停期间的声音不保存，暂停时间也不计入录音时间轴；暂停点是识别上下文的硬边界。
7. 可勾选 **结束后用下方所选模型重新转写**，并在下方选择 large-v3。程序会等 Turbo 退出、释放 GPU 后才加载会后模型。实时草稿和会后稿分别保存，在右侧下拉框中切换。
8. 也可以稍后选中会议记录，点击 **转写录音**。默认 large-v3、自动语言、NVIDIA GPU INT8 混合精度。专业词汇可填入术语提示。
9. 点击 **回听录音**核对内容，或打开 TXT / SRT 文件夹。**复制纪要素材**复制当前选择版本的总结提示和转写稿，由你决定是否粘贴给云端 AI。

**停止实时预览**只停止 Turbo，不会结束录音。实时模型崩溃也不会关闭音频采集。关闭整个程序前仍需结束并保存录音。

实时转写状态会显示待处理的音频秒数。积压超过 8 秒时提示；超过 30 秒则跳到最近 8 秒，跳过范围明确记录到草稿，原始音频完整保留，可会后重转。

阅读区右侧始终显示滚动条。停在底部时自动跟随新内容；向上翻阅后保持当前段落和位置，点击“回到最新”恢复跟随。实时会话的已确认段落不会再因超过 300 段从阅读区移除。

正文使用较大字号；时间和音源以小号灰色显示。连续同音源、间隔不超过 8 秒的句子合并成段（每段最长约 45 秒，避免超长段落），只在段首显示起始时间。仅调整阅读布局，TXT / SRT / JSON 和复制纪要素材仍保留原始逐段时间戳。

首次请做一分钟双向对话测试。耳机连接后点“刷新设备”，再手动选择实际使用的输入、输出设备。

## 本地文件与隐私

默认数据目录：`%USERPROFILE%\MeetingScribeData`（当前用户主目录下）。

左侧“选择文件夹”可以更改新会议的保存位置，并在重启后记住选择。已有会议保留在原位置，仍显示在列表中；模型目录不随之移动。录音或转写过程中不能切换。选择云盘同步目录时，文件可能由对应云盘客户端同步。

- `recordings/`：每次会议一个目录。
- `models/`：离线转写模型，首次下载约数 GB。
- `verification/`：开发时的本地设备验证数据。
- `settings.json`：设备选择和术语设置。
- `recording_location.json`：自选保存目录与历史目录。

每次会议保留：

| 文件 | 用途 |
|---|---|
| `microphone.wav` | 我的麦克风，PCM16 单声道 |
| `system.wav` | 所选输出设备内部音频，PCM16 单声道 |
| `mixed.wav` | 混合回听文件，两路各以 0.5 倍增益混合，避免相加削波 |
| `session.json` | 时间、设备、录音状态、音轨统计 |
| `transcripts/时间戳/` | 每次转写单独保存，重试不覆盖之前的结果 |
| `live_transcripts/时间戳/` | Turbo 实时草稿，独立于会后转写版本 |
| `live_draft.json` | 实时处理中间检查点，保留确认文字、临时文字和跳过范围 |
| `live_capture.json` | 录音进程发布的落盘帧数、暂停边界和状态；不包含音频正文 |
| `transcript.txt / .md / .srt / .json` | 文字、字幕及结构化时间戳 |
| `summary_input.md` | 可检查、脱敏后交给 AI 的纪要素材 |

**录音和转写不上传文件**。联网仅用于 Setup.cmd 安装软件包，以及用户点击下载模型；转写只接受已下载的本地模型，并强制 Hugging Face 离线模式。模型不包含自动云端回退。

把文字粘贴给云端 AI 后，该文字会交给云端处理。剪贴板还可能受 Windows 剪贴板历史 / 跨设备同步设置影响；敏感内容可直接在本地文本编辑器中先脱敏。程序不配置或启用这些 Windows 同步功能。

默认录音目录独立于项目源码。不会自动启动录音，也不会开机自启或后台监听。仓库不包含录音、转写内容、模型或本机路径配置。

## 第一版的边界

- 捕获所选**整个输出设备**的声音，其他软件的提示音也会被录入。不是会议应用专属音源。
- “我 / 麦克风”和“会议声音”是**音源标签**。会议那一路可能有多个人，第一版不识别每人的姓名、不提供逐人声纹分离。
- 不内置回声消除。用耳机可减少重复语音；同一房间多人讲话可能进入麦克风轨。
- 实时模式是短窗口增量识别，不是逐字零延迟流式模型。片段会随上下文修订，长句可能拆段，短词、数字、句首句尾仍可能错漏。重要会议建议会后用 large-v3 重转。
- 实时模式使用 Turbo / NVIDIA GPU；会后转写仍支持 CPU。长录音会后按约 5 分钟窗口处理，边界优先选静音并保留上下文。
- 中英混合、口音、人名、数字、重叠讲话仍需核对。术语提示只帮助识别，不能保证准确。
- 蓝牙重连或切换会议输出设备后，应结束当前录音、刷新设备并开始新录音。不会悄悄切换到其他设备。
- 每次录音上限 8 小时。48 kHz 下两路原始音轨加混合文件合计约 1.04 GB/小时。
- 每秒刷新文件；异常退出后，下次启动会恢复已落盘的 WAV 长度并标注“已恢复”。断电、磁盘故障仍可能损失尾部内容，不能保证零丢失。
- GPU 不可用时会明确报错，可手动选 CPU 重试。取消转写会保留录音和已有完整转写；中间结果可能保存在 `transcription_partial.json`。

## 安装与维护

安装 Python 3.13（64 位），运行 `Setup.cmd`。它将创建独立虚拟环境、安装已验证的 `requirements-lock.txt` 依赖、下载 large-v3 和 Turbo，并生成本机路径配置。GPU 模式需要兼容的 NVIDIA 显卡和驱动；无需安装完整 CUDA Toolkit，使用独立的 NVIDIA 运行库。

`local_paths.json` 和 `runtime-path.txt` 是本机生成文件，换电脑后请运行 Setup.cmd 重新生成。不要将其他机器的配置直接复制过来。

依赖来源：PyPI 上的 PySide6、PyAudioWPatch、faster-whisper、NVIDIA CUDA 库。模型来源：Hugging Face `Systran/faster-whisper-large-v3` 和 `mobiuslabsgmbh/faster-whisper-large-v3-turbo`（供 CTranslate2 使用的转换版）；下载完成记录仓库 revision。模型和依赖遵循各自许可证。

## 验证范围

单元测试（激活安装生成的虚拟环境后）：`python -m unittest discover -s tests`。`scripts/` 下的设备/GPU集成验证脚本需要本机硬件或前序验证产物；`artifacts/` 是本地生成目录，不随仓库发布。

详见 [VALIDATION.md](VALIDATION.md)。已经完成本机真实 WASAPI 双路采集、暂停过滤测试，以及禁用网络连接的 large-v3 GPU 中英合成语音转写。合成语音结果不能代表真实会议准确率；讯飞蓝牙耳机和长时间真实会议尚需实际使用验证。
